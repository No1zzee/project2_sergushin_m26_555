# Primitive DB



Учебный проект на Python: консольное приложение для работы

с примитивной базой данных.



Цель проекта — реализовать создание и удаление таблиц,

добавление, чтение, обновление и удаление записей,

а также сохранение данных в JSON-файлах.



## Текущее состояние



Подготовлена начальная структура Python-пакета.



Реализованы:



- запуск приложения как Python-модуля;

- запуск через команды project и database;

- вывод сообщения DB project is running!.



Операции с таблицами и записями пока не реализованы.



## Требования



- Python 3.12 или новее;

- менеджер проектов и зависимостей uv;

- Git для клонирования репозитория;

- make — при использовании команд Makefile.



Разработка ведётся в Windows с использованием Git Bash.



## Установка



Склонируйте репозиторий и перейдите в его корневую папку.



Установите зависимости и пакет:



```bash

uv sync

```



При необходимости uv загрузит подходящий интерпретатор Python.



## Запуск



Из корневой папки проекта выполните:



```bash

uv run project

```



Дополнительная команда запуска:



```bash

uv run database

```



Запуск как Python-модуля:



```bash

uv run python -m primitive\_db.main

```



На текущем этапе программа выводит:



```text

DB project is running!

```



## Проверка качества кода



Для проверки используется Ruff:



```bash

uv run ruff check .

```



## Сборка пакета



```bash

uv build

```



Собранные файлы появятся в папке dist.



Проверка метаданных собранного пакета:



```bash

uvx twine check dist/\*

```



## Команды Makefile



Если установлен make, доступны следующие команды:



```bash

make install

make run

make lint

make build

```



Они выполняют установку зависимостей, запуск приложения,

проверку Ruff и сборку пакета соответственно.
## Управление таблицами

Запуск приложения:

```bash
uv run database
```

После запуска команды вводятся внутри приложения.

### Создание таблицы

```text
create_table users name:str age:int is_active:bool
```

Поддерживаемые типы: int, str, bool.

Столбец ID:int автоматически добавляется в начало структуры.
Если ID:int указан пользователем, он не дублируется.

Названия таблиц и столбцов должны быть допустимыми идентификаторами,
например users, products, user_name. Имена чувствительны к регистру.

### Просмотр списка таблиц

```text
list_tables
```

### Удаление таблицы

```text
drop_table users
```

### Справка и выход

```text
help
exit
```



### Хранение метаданных

Имена таблиц и структуры столбцов сохраняются в db_meta.json
в текущей рабочей папке.

Для работы с одной и той же базой запускайте приложение
из одной и той же папки.

Файл db_meta.json исключён из Git.

Операции с записями таблиц пока не реализованы.
